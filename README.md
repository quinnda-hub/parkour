# Parkour

A parser-combinator library for OCaml, for human-authored text (config files,
DSLs, small languages). It aims for precise syntax errors, a pleasant API,
opt-in error recovery and stack safety on long and deeply nested input. No
runtime dependencies beyond the OCaml standard library.

```ocaml
open Parkour

let point =
  let+ x = integer <* char ',' and+ y = integer in
  (x, y)

let () =
  match parse point "3,x" with
  | Ok (x, y) -> Printf.printf "%d %d\n" x y
  | Error ds ->
      let source = Source.make ~name:"point" "3,x" in
      List.iter (fun d -> print_string (Diagnostic.render source d)) ds
```

prints

```
error: expected integer, found 'x'
 --> point:1:3
  |
1 | 3,x
  |   ^ expected integer
```

## Documentation

A tutorial and the API reference, built with

```sh
dune build @doc
```

(open `_build/default/_doc/_html/index.html`). The [`examples/`](examples)
directory has complete parsers (JSON, CSV, typed values, a calculator, a
configuration format with error recovery, a small C-like language), each with a
gallery of broken inputs and the errors they produce.
